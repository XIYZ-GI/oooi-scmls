# 数据合成器 2 · 专家结构扩量

入训记录：**57,856 条**。

主体是 `training/expert_expansion/`：把专家结构拆成模块、槽位、连接与供电关系，再重新
装配成新结构，并带候选缓存、覆盖度核算与准入闸门。`curriculum/` 子包负责课程装配、
混合数据集、旧课程评估与展示；`pushdrive/` 是推动式驱动的构造分支；
`training/reinforcement/` 是配套的早期强化学习实验（PPO 策略、回报与报告）。

**源码来源说明**：主要生成文件与历史摘要一致，两项公共依赖（判定器与设计约束）后来
有过修改。历史数据文件与运行配置不在交付范围内。
